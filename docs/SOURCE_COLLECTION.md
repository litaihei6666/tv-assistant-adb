## 采集做什么

`python scripts/collect_sources.py` 只请求固定raw.githubusercontent.com路径的公开文档。允许路径仅为examples/README.md和机型目录内tv.json、debloat.txt，不解释或执行内容。最多6路并发，每次15秒超时，单文件300KB上限。忽略的.work/sources/ab7a89e7缓存及失败清单供本地审查；重试复用文件。下载不完整不覆盖旧索引，使用临时文件替换。

进入Git的索引只有品牌、机型称呼、系统、来源链接、元数据SHA-256和固定unreviewed状态；完整注释不进入交付包。不读取ADB密钥，不扫描家庭网络，不接入电视，不执行上游脚本。

## 人工审查才产生教程

1. 核对来源是否说明首次开启入口，还是只说明已连接后的操作。
2. 分开记录零售型号、系统自报型号、板卡、地区、系统和固件，未知保持未知。
3. 区分USB调试、传统网络入口、TLS无线配对和实际授权，保留重启、待机差异。
4. 普通设置有据可查时整理为有条件参考；需要工厂菜单、未审核APK或证据矛盾时保持待确认，不提供步骤。
5. 原作者自称实测仍是社区来源。平台通用菜单必须注明并附平台文档，不能伪装成该机型逐步实测。
6. 人工写入entries.json后重建页面并检查；索引始终保持待审查，不自动提升级别或授权危险操作。
