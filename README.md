# 电视 ADB 入口资料库

收集电视和电视盒子**如何由本人开启调试**的资料，帮助用户按品牌、型号和系统查找入口。每条记录注明来源、适用范围、验证状态与未知项。离线打开 [查询页面](index.html)，或浏览 [结构化数据](data/entries.json)。

> 这是持续建设的资料库，**不宣称收录齐全或所有型号适用**。选中品牌不证明系统是 Android，打开 USB 调试也不证明无线可连接。不同地区、型号和固件可能不同。

## 怎么查

1. 在电视“关于”或铭牌查看品牌和完整型号；不要公开序列号、MAC 地址或家庭 IP。
2. 打开 `index.html`，输入品牌或型号；核对记录的型号、系统、地区及固件范围。
3. 阅读来源、步骤和限制。只在电视真实出现相应普通设置时操作；找不到时停止并查询厂商说明。
4. 若连接后电视弹出调试授权，由本人确认；完成后按电视实际设置关闭不需要的网络调试。电脑断开不代表电视端开关已经关闭。

页面完全离线，不收集信息；点击来源链接才会打开外部网站。资料不会自动执行任何命令、安装软件或修改电视。

## 数据说明

- `official`：所述具体事实来自厂商或平台官方资料；只代表文档来源，不表示本项目实测。
- `community`：社区文章、个人指南或其他项目资料；不是本项目实测。
- `mixed`：官方和社区共同提供不同部分，见每条限制，不合并为官方验证。
- `firsthand_report`：当事人一次操作的记录；不代表完整固件匹配或兼容认证。
- `unverified`：仅用于引导识别与收集资料，暂无可核实入口。

`reference` 是可以按前提查阅的文档参考；`unresolved` 表示没有本项目可提供的安全具体步骤；`user_report` 是一次用户反馈。具体字段和更新流程见 [数据格式](docs/DATA.md)。资料来源中其他项目自称的机型数量或实测，不等于本项目的实测数量。

资料的当前覆盖及主要空缺见 [覆盖情况](docs/COVERAGE.md)。

当前已整理 **76 条记录**（58 条有条件参考、1 条用户反馈、17 条入口待确认），另有 **260 条机型来源索引、77 个来源品牌/系列标签**。索引只有元数据和来源链接，没有操作步骤，不算已完成教程；两部分有重叠，不能相加作为支持机型数。型号之外还须核对系统、固件、地区。

查询页下方可展开“机型资料来源索引”，中文常见品牌名和英文品牌名均可检索；只匹配来源索引时会自动展开。收集方法、固定版本及后续审查顺序见 [来源采集说明](docs/SOURCE_COLLECTION.md)。

## 本地维护

使用 Python 3.10+；搜索交互测试还需要 Node.js，无需第三方依赖：

```text
python scripts/build.py
python -m unittest discover -s tests -v
python scripts/build.py --check
node tests/search.test.js
```

构建只根据本地 JSON 生成静态页面，不联网、不接入设备。

维护者可运行 `python scripts/collect_sources.py` 从固定提交读取公开机型元数据，缓存位于忽略的 `.work/`。这一步需要联网，但不会执行上游脚本、安装 APK、扫描局域网或连接电视；存在下载失败时保留原索引。
